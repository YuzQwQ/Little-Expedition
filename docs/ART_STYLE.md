# Little Expedition｜统一美术风格规范

本规范适用于《Little Expedition》（小小远征）的角色、怪物、Boss、场景、道具、战斗特效与 UI 图标。

## 一、核心画风

- **手绘童话绘本风格（Hand-painted Storybook Fantasy）**。温暖柔和，具有精致的奇幻插画质感，像一本可以走进去冒险的绘本。
- **Q 版造型（Chibi Character Design）**。人物与怪物采用约 2.5～3 头身，大头、短四肢，轮廓简洁圆润，避免过度幼态化。
- **柔和水彩与轻厚涂（Soft Watercolor & Painterly Shading）**。保留轻微纸张纹理、自然笔触与柔和过渡。
- **清晰的手绘轮廓（Clean Hand-drawn Outlines）**。使用深棕色、深灰色或与物体协调的描边，避开生硬的纯黑粗线。
- **适度夸张的奇幻设计（Whimsical Fantasy）**。装备、武器、服饰与怪物可采用独特的童话造型，保持结构清晰、易于辨识。

## 二、色彩与光影

- 以中等饱和度为主，用局部鲜艳色突出重点。暖色自然底色与柔和冷色阴影形成对比。
- 采用简单明暗分区和轻微笔触塑造体积。通过色块、笔触与局部高光区分金属、布料、木材和石材。
- 画面明亮清晰，避免苍白、低对比、过度甜腻、摄影式光照、强镜面反射及大面积霓虹发光。

## 三、人物与怪物

- 统一约 2.5～3 头身。五官简洁，表情鲜明、有性格，避免复杂动漫面部细节。
- 保持清晰剪影与简化细节，缩小后仍可辨认。服饰和武器以中世纪奇幻冒险为基础，可融入炼金术、魔法与古老遗迹元素。
- 用姿态、眼神和武器表现敌人的威胁感。敌人可以凶恶、古怪或危险，避开血腥恐怖、写实怪诞及全员过度可爱。
- Boss 可以拥有更夸张的轮廓和体型，与普通敌人保持同一世界的视觉语言。

## 四、视角与游戏可读性

- 战斗角色和怪物采用略带俯视感的四分之三视角，能看见头顶、肩部与身体正面或侧面。完整正面立绘不作为战斗素材。
- 场景、地面与建筑和角色采用相容的俯视透视与比例。避免过强透视、复杂背景及遮挡角色的装饰。
- 优先保证攻击动作、武器朝向、角色轮廓与碰撞范围的可读性。

## 五、各类素材

- **战斗角色和敌人**。造型比例统一，姿态自然，动作具有表现力，便于制作独立精灵图。
- **遗物和道具图标**。采用精致手绘的奇幻实物，例如戒指、吊坠、古老器皿、植物、宝石、护符或魔法器具。主体居中完整，剪影清晰，避免复杂背景和大量装饰粒子。
- **地图与场景**。采用柔和手绘的草地、石砖、古老遗迹及自然装饰。材质细节适中，保持各区域的风格一致，确保角色和敌人在场景中醒目。
- **战斗特效**。采用简洁的 2D 手绘魔法效果。玩家火焰用橙红和金黄，自然用绿色和黄绿，寒冰用浅蓝和蓝白，奥术用蓝紫和淡紫。
- **敌方远程弹幕**。统一用醒目的红色几何形状，省去复杂材质与独立美术设计，优先保证辨识度。

## 六、严格避免的风格

- 写实摄影、3D 模型渲染质感、像素画、赛璐璐硬边上色、过于精细的日式二次元立绘。
- 美式粗线条卡通、过度幼态的儿童贴纸、黑暗写实恐怖、高饱和霓虹赛博朋克。
- 大量随机光效、粒子、复杂背景、过度装饰、无意义纹样和结构混乱。

## 七、输出规范

1. 主体完整，避免裁切武器、头部、四肢与重要装饰。
2. 使用透明背景。工具无法输出透明背景时选用便于后期处理的纯色背景。
3. 除明确要求外，省去文字、标题、水印、边框和展示底座。
4. 只绘制指定物件或角色。
5. 保持造型简洁，方便后续制作动作动画。
6. 同类素材统一比例、描边粗细、光照方向及色彩饱和度。
7. 在游戏实际显示尺寸下检查剪影与主要特征，优先保证可读性。

所有素材应像由同一位插画师为同一本奇幻冒险绘本绘制。角色可爱而有性格，怪物危险而保留绘本气质，世界精致且简洁。游戏可读性优先于装饰性。
